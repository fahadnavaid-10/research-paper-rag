# 🚀 Cardiology Research Paper RAG
A focused Retrieval-Augmented-Generation (RAG) system that turns a corpus of cardiology research PDFs into a question-answering API. It serves clinicians, researchers, and ML/AI teams who need precise, citation-backed answers from domain literature without full-text search noise.
